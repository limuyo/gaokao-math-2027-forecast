# 2027 广东高考数学 · 选择压轴题十年洞察与预测

Ten-Year Insights & Forecast for Guangdong Gaokao Math MCQ Finale Questions (2027)

基于 2017–2026 年（含 2007 理）全国Ⅰ卷 / 新高考Ⅰ卷选择压轴题的结构化语料，用多模型竞争、滚动回测、网格调参与 bootstrap 置信区间构建的预测工具，含交互式单文件网页。

## 文件一览

| 文件 | 说明 |
|---|---|
| `2027广东高考数学选择压轴题预测.html` | 交互网页（双击即用，零外部依赖）：十年档案、数据看板、双视角 2027 预测、答案选项分析、模拟押题 |
| `engine.py` | 预测引擎（Python 标准库）：频率衰减 / 马尔可夫 / hazard / 风格指纹 / 命题人分段五模型 + BMA 融合 + 答案组合预测器，`python engine.py` 可复现 `engine_output.json` |
| `core_questions.json` | 21 题结构化语料（L1/L2/L3 三级标注 + 情境 + 设问 + 答案字母） |
| `engine_output.json` | 引擎输出：2027 考点分布（含置信区间）、回测成绩单、单选×多选联合分布、答案组合概率 |
| `重型引擎计划表.html` | 项目计划表与验收标准（可勾选） |
| `近十年广东高考数学选择压轴题汇编.pdf` | 原始汇编文档（AI 检索整理，含来源与校核说明） |

## 诚实预期

每年仅 2–3 个数据点，瓶颈是数据量而非算力。回测显示任何模型都无法可靠押中单一考点（Top1 命中率 14.3%，不高于随机 16.7%；Top3 命中 71.4%）。本工具的价值是把不确定性量化、给出校准概率与复习覆盖策略，**不构成押题承诺**；正式信息以教育部教育考试院及广东省教育考试院公布为准。
